# Lib
- Interpreter English words follow the shared hindi-english-words rule; only blocks with leftover English letters get one guarded swap-only pass, so clean output costs nothing extra.
- Dub playback treats video still inside a just-spoken part as a silent wait; only a >1 s backward jump returns to a finished part, so no part is spoken twice.
- Media audio falls back from refused WebCodecs codecs to AAC-LC-labelled/LC-core decoding, then a size-capped whole-file Web Audio decode, because phone browsers often refuse HE-AAC reels while still playing AAC-LC.
- As-it-is transcript is an opt-in `verbatim` flag with its own interpret/review/English-letter prompts and no word budget; it adds a separate identity/checkpoint suffix only when on, so simple-Hindi caches and resumes stay unchanged.
- Unfinished interpretation checkpoints are listed on the YouTube page (key parsed back to source/settings) so cleared inputs never strand saved paid work.
- Narration downloads make speech pieces a few at a time (NARRATION_PARALLEL, joined in order), retry only a cut-off piece (bounded, never credits/access refusals), keep finished pieces per text/voice so a retry makes only the rest, and save the finished file automatically.
- Simple-Hindi common-sense clarity (complete who/what sentences, first-mention meaning for unknown foreign names, 0-9 digits, one approximate rupee hint from RUPEE_RATES) and the expert-interpreter craft rule (soft word budget, ~15% overrun allowed) lives in hindi-readability and is shared by interpreter + existing reviewer (no extra AI pass); display/download join mid-sentence paragraph breaks and normalise digits without changing saved text, so saved narration fingerprints stay valid.
